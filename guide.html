AI인공지능고등학교 _화난춘향이

Claude로 HTML 활동지 만들고 배부하기

수업 자료만 있으면 됩니다. 코딩을 몰라도 Claude와 대화하며 활동지를 만들고, 링크로 배부하고, 학생 응답을 구글 시트로 모을 수 있어요.

  • 1 준비물
  • 2 프롬프트
  • 3 수정하기
  • 4 제출 연결
  • 5 링크 만들기
  • 6 점검

이렇게 만들어져요

  • 수업 흐름대로 구성된 활동지 웹페이지 1개 (HTML 파일 하나)
  • 모바일·PC 모두 보기 좋은 화면, 입력 내용 자동 저장
  • 이름·학번 입력, 제출하기 버튼 → 내 구글 시트에 자동 수합
  • 인쇄 · PDF 저장 버튼, 학교 이름과 로고, 직접 만든 그림
흐름: 자료 정리 → Claude에게 요청 → 다듬기 → 시트 연결 → GitHub로 링크 만들기 → 배부

1Claude에게 줄 자료 준비

아래를 미리 정리해 두면 한 번에 원하는 결과가 나옵니다. 모르는 항목은 “알아서”라고 해도 됩니다.

항목예시필수
대상·단원고1, 인공지능 기초 · 디지털 윤리 · 윤리적 딜레마필수
수업 시간과 기기1차시 50분, 학생 1인 1기기필수
활동 흐름활동 1: 사례 판단 → 활동 2: 모둠 토론 → 정리필수
학생이 쓰는 방식찬성/반대 고르고 이유 쓰기, 근거 직접 검색, AI 사용 시 AI 이름과 프롬프트 기록필수
제출 방식이름·학번 입력, 제출 버튼 → 구글 시트필수
교과서 쪽 사진참고용 스크린샷 (내용 이해용이며 그림은 그대로 쓰지 않음)권장
디자인“깔끔하고 세련되게”, 선호 색상이 있으면 말하기선택

저작권 주의 교과서 삽화와 문장은 그대로 쓰지 마세요. “그림은 직접 만들고, 글은 학생 눈높이로 새로 써줘”라고 요청하면 됩니다.

2Claude에게 이렇게 요청하세요

아래 프롬프트를 복사해서 [대괄호] 부분만 바꿔 보내세요. 교과서 쪽 사진이 있으면 함께 올립니다.

[고등학교 1학년] [인공지능 기초] 수업 중 [디지털 윤리 - 윤리적 딜레마] 단원 활동지를 HTML 파일 하나로 만들어줘.

수업: [1차시 50분], 학생은 1인 1기기 사용
활동 흐름:
- 활동 1: [사례 1, 2를 읽고 찬성/반대를 고른 뒤 이유 쓰기, 두 사례 비교]
- 활동 2: [함께 해결하기. 개인이 입장을 고르고 근거를 직접 찾거나 AI로 찾기. AI를 쓰면 사용한 AI 이름과 프롬프트를 쓰게 하기. 모둠 결론 쓰기]
성취도 평가 문항은 넣지 않아.

입력과 제출:
- 맨 위에 이름·학번·모둠 입력칸
- 맨 아래에 [제출하기] 버튼을 만들고, 구글 시트에 자동 저장되도록 Google Apps Script 코드도 같이 줘. 웹 앱 주소를 넣을 자리는 비워 둬.
- 인쇄 · PDF 저장 버튼, 입력 내용 브라우저 자동 저장

디자인:
- 깔끔하고 세련된 스타일, 색상은 알아서 정해줘
- 모바일과 PC 모두 보기 좋은 반응형
- 학교 이름은 [AI인공지능고등학교]이고 간단한 로고도 만들어줘
- 교과서 삽화는 저작권 때문에 쓰지 말고, 상황 그림은 직접 SVG로 만들어줘
- 사례 설명은 교과서 문장을 그대로 쓰지 말고 [고1] 눈높이로 새로 써줘
만들어 준 파일은 대화창에서 내려받을 수 있어요. 내려받은 파일 이름을 index.html로 바꿔 두세요.

3마음에 들 때까지 다듬기

한 번에 완벽할 필요는 없어요. 바꾸고 싶은 점을 짧게 말하면 됩니다.

  • “사례 2의 그림을 더 눈에 띄게 만들어줘”
  • “전체 색상을 보라색 계열로 바꿔줘”
  • “맨 위 학교 이름 옆에 ‘_만든이 이름’을 넣어줘”
  • “글자를 조금 더 크게 해줘”, “질문을 이렇게 바꿔줘: …”
직접 파일을 고쳐서 올리고 싶다면 그 파일을 Claude에게 보여주며 “이 파일 점검해줘”라고 해도 됩니다.

4학생 응답을 구글 시트로 모으기

제출 버튼이 있는 활동지는 구글 시트와 연결해야 작동합니다. 약 5분이 걸려요.

  1. 구글 시트를 새로 만듭니다.
  2. 확장 프로그램 → Apps Script를 열고, Claude가 준 .gs 코드를 붙여넣어 저장합니다.
  3. 배포 → 새 배포 → 유형: 웹 앱을 고릅니다. 실행 사용자는 나, 액세스 권한은 모든 사용자로 설정하고 배포합니다. 처음에는 권한 승인 창이 뜨니 승인합니다.
  4. 나온 웹 앱 주소(https://script.google.com/…)를 복사합니다.
  5. Claude에게 “이 주소를 제출 주소로 넣은 파일로 다시 만들어줘” 하고 주소를 붙여넣습니다. (파일에서 SUBMIT_URL 부분을 직접 바꿔도 됩니다.)
꼭 지켜요 Apps Script의 항목 이름 목록을 바꾸면 시트 칸이 어긋납니다. 활동지의 항목을 수정했다면 Claude에게 “활동지에 맞게 Apps Script도 다시 맞춰줘”라고 하세요.

제출 후에는 시트에서 학번별로 가장 최근 행을 보세요. 다시 제출한 학생은 행이 여러 줄 생깁니다.

5GitHub에서 링크(웹 주소) 만들기

무료이고 설치할 프로그램도 없어요. 브라우저만 있으면 됩니다.

저장소 만들고 파일 올리기

  1. github.com에 가입하고 로그인합니다.
  2. 오른쪽 위 + → New repository를 누릅니다.
  3. Repository name에 영문 이름(예: worksheet-ethics)을 쓰고 Public으로 두고 Create repository를 누릅니다.
  4. uploading an existing file 링크를 눌러 index.html을 끌어다 놓고 Commit changes를 누릅니다.
파일 이름은 반드시 index.html (소문자)이고, 폴더 안이 아니라 저장소 맨 앞에 있어야 합니다.

웹페이지로 공개하기

  1. 저장소의 Settings → Pages로 들어갑니다.
  2. Source는 Deploy from a branch, Branch는 main, 폴더는 / (root)를 고르고 Save를 누릅니다.
  3. 1~3분 기다린 뒤 새로고침하면 맨 위에 Visit site와 주소가 나타납니다.

주소 모양: https://내아이디.github.io/저장소이름/

고치고 싶을 때

저장소에서 Add file → Upload files로 같은 이름의 index.html을 다시 올리면 덮어쓰기됩니다. 주소는 그대로이고 반영에 1~2분 걸려요.

주소가 안 보이거나 404가 나와요
  • 1~3분 더 기다린 뒤 Settings → Pages를 새로고침하세요.
  • 저장소 위쪽 Actions에서 초록 체크가 되었는지 확인하세요.
  • 파일 이름이 index.html인지, 폴더 안에 들어가 있지 않은지 확인하세요.
GitHub 아이디나 저장소 이름을 바꾸면?

활동지 주소도 바뀌고 예전 주소는 열리지 않아요. 이미 배부했다면 수업이 끝난 뒤에 바꾸세요.

6배부 전 점검

  • ☐ 내 링크를 열어 이름·학번 넣고 제출해서 시트에 한 줄이 들어오는지 확인
  • ☐ 스마트폰과 학생용 기기, 학교 와이파이에서도 열리는지 확인
  • ☐ 테스트로 들어온 행 삭제 (맨 윗줄 제목 행은 그대로 두기)
  • ☐ 링크를 PPT에 띄우거나 QR코드로 만들어 두기 (QR코드 생성기에 주소 입력)
알아두세요 Public 저장소라서 파일 안의 Apps Script 주소가 누구에게나 보일 수 있어요. 학생 정보는 파일에 들어 있지 않지만, 링크는 수업 대상 학생에게만 알려 주세요. 학생의 입력 내용은 각자 기기에만 저장되므로 수업은 한 기기로 끝까지 하도록 안내하세요.

학교 네트워크에서 github.io나 구글 스크립트가 막힌 경우에는 “내용 복사”나 “인쇄 · PDF 저장”으로 대신 제출하게 할 수 있어요.
